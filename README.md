# GianeCycleHub

GianeCycleHub is a motorcycle parts shopping and online rental website prototype built with PHP.

## Features
- Online motorcycle booking and reservation
- GPS location access for pickup and drop-off
- User verification with photo upload
- Role-based access for admin and user
- Admin navigation and user navigation

## Default login accounts
- Admin: admin@gianecycle.com / admin123
- User: user@gianecycle.com / user123

## Run locally
1. Place the project folder inside your local web server root (for example, htdocs in XAMPP).
2. Start Apache in XAMPP.
3. Open http://localhost/GianeCycle in your browser.

## Files
- `index.php` - landing page
- `login.php` - login form
- `register.php` - user registration
- `user-dashboard.php` - buyer dashboard
- `admin-dashboard.php` - shopkeeper dashboard
- `rentals.php` - rental booking page
- `shop.php` - parts catalog
- `gps.php` - location page
- `verification.php` - photo verification
- `profile.php` - account profile
